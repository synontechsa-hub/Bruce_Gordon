# BGrafX v2 - Design System & Creative Direction

Status: Active visual guidance
Last updated: 2026-08-14

## Design Philosophy

BGrafX v2 is a premium creative portfolio.

The website should communicate professionalism, confidence and craftsmanship while remaining creative and memorable.

The portfolio is the hero.

The interface exists to support the work, not compete with it.

Every design decision should help build trust and encourage a visitor to become a client.

---

# Creative Direction

Overall Style Mix

* 70% Premium Creative Studio
* 20% Designer's Workshop
* 10% Editorial Portfolio

Avoid creating a website that feels like:

* a generic SaaS landing page
* a template marketplace theme
* a heavily stylised pop-art website
* a gaming website
* an overly corporate finance website

The final result should feel timeless rather than trendy.

# Visual Hierarchy

Large typography should create visual impact.

Use generous spacing.

Allow sections to breathe.

Keep layouts clean.

Avoid visual clutter.

Only highlight important information.

The eye should naturally flow down the page.

---

# Colour Palette

Primary Background

Warm paper / off-white

Primary Text

Near black

Secondary Text

Muted grey

Accent Colour

One controlled accent colour only.

The accent should draw attention to calls-to-action and important interface elements.

Avoid excessive use of bright colours.

---

# Typography

Use only two font families.

Display Font

Large

Bold

Editorial

Condensed where appropriate

Body Font

Highly readable

Professional

Neutral

Avoid decorative fonts except for very small workshop annotations.

---

# Layout

Use a strong grid.

Allow asymmetrical compositions where they improve visual interest.

Use large margins.

Avoid cramped layouts.

Every section should feel intentional.

---

# Imagery

Use real portfolio work wherever possible.

Project imagery should dominate over decorative graphics.

Images should be large and high quality.

Avoid stock photography where possible.

---

# Designer's Workshop Elements

Use sparingly.

Examples include:

Paper textures

Masking tape

Crop marks

Registration marks

Grid paper

Pencil notes

Sketch lines

Colour swatches

These elements should enhance the experience without distracting from the work.

# Animation Philosophy

Animation should communicate quality.

Animation should never exist purely because it looks impressive.

Preferred animations include:

Fade

Slide

Reveal

Subtle scale

Hover transitions

Image movement

Section reveals

Avoid:

Long intro animations

Constant floating elements

Overly complex parallax

Excessive motion

Animations longer than necessary

Support reduced-motion preferences.

## Alyssa assistant

Alyssa is a lightweight virtual receptionist, not a competing feature or a generic chat widget. Her visual language belongs to the same workshop/editorial system: compact black panels, controlled yellow accent, clear type, and a deliberately small footprint.

- Keep her launcher clear of primary calls to action, especially on phones.
- On compact phone viewports, defer the launcher until the visitor has moved beyond the hero.
- Use concise, human-sounding scripted guidance and a direct hand-off into the enquiry form or WhatsApp.
- Tour overlays should help orientation, not obscure the page indefinitely; every tour state needs a clear close or finish action.
- Avoid adding conversational complexity, data collection or decorative motion that distracts from the work.

---

# Mobile Design

Mobile is not a secondary experience.

Every section must be intentionally designed for mobile.

Do not create duplicate desktop and mobile markup.

Responsive layouts should adapt naturally across screen sizes.

Touch targets should be comfortable.

Typography should remain readable.

Navigation should be simple.

---

# Accessibility

Maintain strong colour contrast.

Provide visible focus states.

Use semantic headings.

Support keyboard navigation.

Support reduced-motion preferences.

---

# Overall Impression

When a potential client visits BGrafX they should think:

"This designer is experienced."

"This feels premium."

"They clearly know what they're doing."

"I'd trust them with my brand."

The website should leave a lasting impression through restraint, craftsmanship and attention to detail rather than visual excess.
