# BGrafX v2 - Product Requirements Document (PRD)

## Project Overview

BGrafX is the personal portfolio and freelance business website of Bruce Gordon, an experienced South African Graphic Designer, Web Designer and Software Developer with over 22 years of professional experience.

The purpose of this redesign is to transform the existing portfolio into a modern, premium-quality website that inspires confidence and converts visitors into paying clients.

This is not a redesign of the existing visual identity.

It is a complete rebuild using the existing content as the foundation.

---

# Primary Goals

The website must:

* Present Bruce Gordon as an experienced creative professional.
* Showcase a diverse range of work.
* Demonstrate both design and technical capability.
* Generate freelance enquiries.
* Encourage WhatsApp and email contact.
* Build credibility through presentation rather than exaggerated claims.

---

# Success Criteria

A visitor should understand within the first 10 seconds:

* Who Bruce Gordon is.
* What services are offered.
* Why they should choose BGrafX.
* How to make contact.

# Mobile Requirements

The website MUST be designed mobile-first.

There must not be separate desktop and mobile versions of sections.

Every page must be fully responsive.

The experience on mobile should feel intentionally designed rather than a scaled-down desktop layout.

Supported breakpoints:

360px

390px

430px

768px

1024px

1280px

1440px

# Definition of Done

The website is considered complete when:

* All pages are functional.
* Desktop and mobile are fully responsive.
* Lighthouse scores are strong.
* Accessibility passes basic audits.
* SEO is configured.
* Portfolio content is genuine.
* Navigation works.
* Contact methods work.
* The site is production-ready for deployment.
